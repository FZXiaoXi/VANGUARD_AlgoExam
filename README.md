# VANGUARD 算法组代码调试考核

## 考核说明

代码调试考核目录下有 `Debug_1` 与 `Debug_2` 两个项目。考查代码 Debug 能力的同时，将考查 git 与 github 的使用。

- `Debug_1` 考查 ROS2 功能包构建、节点通信与自定义消息接口基础知识。考核将设置环境、配置等错误，不设置逻辑错误。

    难度：较为基础

    建议时间：20min

    评分标准：

    - 能够复现构建或运行现象，并根据终端输出、节点信息和话题信息缩小问题范围；
    - 能够正确定位问题；
    - 只修改题目要求范围内的文件，不通过修改测试数据、硬编码输出或删除节点绕过问题。

- `Debug_2` 考查C++代码的 Bug 发现、定位与调试能力。考核将设计若干逻辑 Bug ，不会设置直接报错等明显 Bug ，需尽可能发现并修复验证。

    难度：难易错误点均有设置，总体较为困难。
    
    建议时间：50min

    评分标准：按找出 Bug 点评分，分值由找出的 Bug 点难度决定。提前了解多加练习，尽可能完成。

    - 能够使用调试器 / printf  / cout 等复现错误；
    - 能够理解错误原因、影响范围和修复思路，而不是只修改到某个测试通过；
    - 没有完成修复的 Bug，也应记录现象、定位依据和当前结论，按过程给予相应评分。

### 考核时间：90分钟 (包括客观题)
